# GeorgeOS

My own browser operating system that contains many different apps and customization features that includes my socials

## Features

- **Lock screen** - Time and enter button to enter into the desktop 
- **Window manager** - draggable, resizable, focusable, closable apps with titlebars and fullscreen support
- **Multi-workspace** - 4 switchable workspaces accessible through the top right grid button or keyboard shortcuts
- **Apps (dock)**
  - **Calculator**
  - **Photos** - browse your own images
  - **Paint** - draw with brush/eraser, clear, and save
  - **Weather** - live weather via Open-Meteo API
  - **Camera** - take your own pictures
  - **Mail**, **Projects**,  **Holy Moly**, **LinkedIn**
  - **YouTube**, **Instagram**, **System Breach**
  - **Customization** - switch desktop themes between MacOS, Windows 11, and Windows XP
