# GeorgeOS

My own browser operating system that contains many different apps and customization features that includes my socials

## Features

- **Lock screen** - Live date and time with an enter button to unlock into the desktop
- **Desktop shell** - Wallpaper, status clock, and a desktop workspace switcher
- **Window manager** - Draggable, resizable, focusable, closable apps with titlebars and fullscreen support
- **Multi-workspace** - 4 switchable desktops in a 2x2 grid, opened from the top-left pill or with keyboard shortcuts (Ctrl+Alt+Arrow keys or Ctrl+Alt+1–4)
  - **Workspace overview** - Bird's-eye preview of all desktops, with drag-and-drop to move windows between them
- **Sound effects** - Web Audio chimes when unlocking, opening, and closing windows, plus tap feedback
  - Mute/unmute from the console with `__georgeosToggleMute()`

## Apps

- **Calculator** - Basic arithmetic with a clean keypad
- **Photos** - Browse the built-in library, upload your own images, and set any photo as the desktop background
- **Paint** - Paint over photos using brush/eraser with adjustable color and size, clear the canvas, and save as PNG
- **Weather** - Live weather for your area using device geolocation (or IP-location fallback), with a refresh button
- **Camera** - Start the webcam, take photos, and record video with downloadable results
- **Mail** - Send messages straight to curious.george71511@gmail.com
- **Projects** - Browse my GitHub repositories live
- **Holy Moly** - My Pixel Forge Game Jam game
- **LinkedIn** - My LinkedIn profile
- **YouTube** - My channel, Georges Attire Official
- **Instagram** - My Instagram, @georgesunreal
- **System Breach** - My Pixel Forge Game Jam game
- **Customization** - Switch desktop themes between macOS, Windows 11, and Windows XP, and adjust icon and text sizes
  - Theme and size preferences are saved and restored automatically
