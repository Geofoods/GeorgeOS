## Features

- **Boot animation** - Animated startup sequence with a glowing logo, loading bar, and light flash into the lock screen
- **Lock screen** - Live date and time with an enter button to unlock to the desktop
- **Desktop shell** - Wallpaper, status clock, and a desktop workspace switcher
- **Window manager** - Draggable, resizable, focusable, closable apps with title bars and fullscreen support
- **Multi-workspace** - 4 switchable desktops in a 2x2 grid that can be switched from eachother in two clicks
- **Workspace overview** - View of all of the desktops
- **Sound effects** - Sound effects for entering and exiting applications
- **Light/Dark mode** - Change the UI style
- **Widgets** - Clock and Calendar widget

## Apps

- **Calculator** - Do math
- **Photos** - Browse your own photos that you have taken and set them as the background photo
- **Paint** - Paint over photos using a brush/eraser with adjustable color and size, clear the canvas, and save as PNG
- **Weather** - Live weather in your current location
- **Camera** - Photos, Videos, that are downloadable
- **Mail** - Send messages straight to my email
- **Projects** - Browse my GitHub repositories live
- **Holy Moly** - One of my games that I made
- **LinkedIn** - My LinkedIn profile
- **YouTube** - My channel, Georges Attire Official
- **Instagram** - My Instagram, @georgesunreal
- **System Breach** - One of my games that I made
- **Profile Creator** - Create profiles
- **Customization** - Switch desktop themes between macOS, Windows 11, and Windows XP, and adjust icon and text sizes
  - Theme and size preferences are saved and restored automatically
